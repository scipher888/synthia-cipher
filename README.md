# Synthia Cipher

The author landing page for **Synthia Cipher** — a pen name. It introduces two publications as equal destinations under one author identity:

- **Signal & Noise** — the rigorous side; one idea each week, taken through adversarial review.
- **Intuition** — the early side; hunches and arguments still forming.

AI tools are used to draft and pressure-test the work; the editorial judgment, final wording, published claims, and any errors are the human author's. The portrait is an illustration of the pen name, not a photograph of a real person.

Live: https://scipher888.github.io/synthia-cipher/

Static site — GitHub Pages from `main` root, no build step.
